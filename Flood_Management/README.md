# Flood Management System

## Run locally with XAMPP MySQL

1. Open the XAMPP Control Panel and start **MySQL**. Apache is not required.
2. In PowerShell, change to the project folder and install the Python dependency:

   ```powershell
   cd "C:\Users\User\OneDrive\Desktop\Flood_Management"
   py -m pip install -r requirements.txt
   ```

3. Start the Python web server:

   ```powershell
   py app.py
   ```
